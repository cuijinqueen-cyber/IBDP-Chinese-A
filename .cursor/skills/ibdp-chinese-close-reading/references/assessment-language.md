# 评估用语与反馈话术

简化自 IB 语言与文学分析类任务的常见期待，供站点 rubric 与自动反馈文案使用。非正式官方量表。

## 四维速查（学生可见短版）

1. **理解与洞察**：是否抓住文本态度、矛盾或关键张力？是否回应引导问题？  
2. **证据**：是否引用具体词句？引文是否支撑观点？  
3. **手法与效果**：是否准确命名手法？是否分析对读者/意义的作用？  
4. **表达组织**：段落是否有观点句？分析是否连贯，少复述情节？  

## 反馈话术模板

### 精读批注

- 弱：「这里用了比喻。」  
- 强：「把……比作……，使……的情绪变得可感，并暗示……。」

### 手法识别

- 正确：肯定名称 + 用一句话点明效果 +（可选）指出易混淆点  
- 部分正确：名称对但位置/范围不准 → 提示收窄到关键词  
- 错误：不直接给最终答案（第一轮）；给思考提示：「注意动词的非常规搭配」；第二轮再揭示  

### 分析写作

缺证据 →「先插入一句原文，再解释。」  
有证据无效果 →「读者读到这里会有什么感受或判断上的变化？」  
情节复述 →「把『发生了什么』改成『作者如何让我们感受到……』。」  
空泛主题 →「主题要落到具体词句：哪一个词触发了这个解读？」  

## 自评 Checklist（可做成可勾选 UI）

- [ ] 首句回应引导问题或提出明确主张  
- [ ] 至少一处带引号的文本证据  
- [ ] 点名至少一种手法（或文体特征）  
- [ ] 说明该手法的效果（非仅定义）  
- [ ] 结尾将局部分析连回文本整体目的/态度  
- [ ] 少复述，多分析；句子通顺  

## 分数呈现（若需要）

优先用 **熟练度标签**（起步 / 发展中 / 熟练 / 优秀）+ 一条改进建议，避免伪装成官方分。若做分数，明确标注「课堂练习分，非 IB 预测分」。
