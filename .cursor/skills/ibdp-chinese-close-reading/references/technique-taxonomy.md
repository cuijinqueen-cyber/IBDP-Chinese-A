# 文学与语言手法词表（教学用）

用于统一 `techniqueId`、练习选项与反馈文案。可按课程增删，但 **id 稳定**，避免破坏已有答案。

## 修辞与表达

| id | 中文 | English | 效果提示（示例） |
| --- | --- | --- | --- |
| metaphor | 比喻（隐喻） | metaphor | 建立形象联想；使抽象情感具体可感 |
| simile | 明喻 | simile | 通过「像/如」显式比较，突出相似点 |
| personification | 拟人 | personification | 赋予非人对象以动作/情感，增强生动性与移情 |
| hyperbole | 夸张 | hyperbole | 强化情绪或态度，制造张力或讽刺 |
| irony | 反讽 | irony | 字面与实际意味反差，促使读者反思 |
| parallelism | 排比 | parallelism | 增强气势与节奏，强调并列观念 |
| repetition | 反复 | repetition | 突出关键词，形成节奏或执念感 |
| rhetorical-question | 设问/反问 | rhetorical question | 引导思考或强化语气，拉近/施压读者 |
| contrast | 对比 | contrast | 凸显差异，清晰化态度或主题 |
| imagery | 意象 | imagery | 调动感官，营造氛围与象征空间 |
| symbolism | 象征 | symbolism | 以具体事物承载抽象意义 |
| allusion | 用典/典故 | allusion | 借互文丰富含义，预设读者文化背景 |
| tone-shift | 语气转变 | tone shift | 标记态度转折，推动情感或论证走向 |

## 结构与叙事（文学）

| id | 中文 | English | 效果提示 |
| --- | --- | --- | --- |
| flashback | 倒叙/插叙 | flashback | 补充动机与背景，改变信息揭示节奏 |
| foreshadowing | 铺垫/伏笔 | foreshadowing | 制造期待与不安，增强连贯性 |
| unreliable-narrator | 不可靠叙述 | unreliable narrator | 制造认知落差，邀请读者质疑 |
| motif | 母题反复 | motif | 通过重复意象深化主题 |
| pacing | 节奏控制 | pacing | 短句加速紧张；长句延展沉思 |
| enjambment | 跨行（诗） | enjambment | 打破行末停顿，制造流动或悬置 |
| stanza-break | 节的划分 | stanza break | 组织思路/意象群，控制呼吸与停顿 |

## 非文学/语言与文学共通

| id | 中文 | English | 效果提示 |
| --- | --- | --- | --- |
| direct-address | 直接称呼读者 | direct address | 建立关系，增强劝说或亲密感 |
| statistics | 数据/列举事实 | statistics | 增强客观性与可信度（需防堆砌） |
| expert-opinion | 援引权威 | expert opinion | 借权威加强论点 |
| anecdote | 轶事/例子 | anecdote | 以具体故事提高共鸣与可记性 |
| concessive | 让步后转折 | concession | 示公允后强化本方论点 |
| lexical-field | 语义场/词语集群 | lexical field | 同一语义场词汇烘托主题氛围 |
| modality | 情态（必须/可能等） | modality | 调节肯定程度与作者立场 |
| syntax-variation | 句式变化 | syntax variation | 长短句、倒装等影响节奏与焦点 |

## 出题约定

- 一道题主打 **1 个核心手法**；次要手法可在反馈中提及  
- 选项干扰项应为「文中可能被误认」的手法，而非无关名词  
- 标准答案必须含 `effect` 字段；仅有名称视为不合格内容  
- 诗歌与散文共用词表；UI 可按 `genre` 过滤显示子集
