# 分析句式支架（可插入写作区）

学生点选后插入编辑器，`【】` 内为待填槽。保持学术语气，避免口语化空话。

## 基础（证据 + 手法 + 效果）

1. 文中「【引文】」运用了【手法】，使【对象/情绪/场景】显得【效果】，从而【对读者的影响】。  
2. 作者以【手法】呈现「【引文】」，将【A】与【B】联系起来，突出了【态度/主题】。  
3. 「【引文】」中的【关键词】构成【意象/语义场】，营造出【氛围】，暗示【深层含义】。  

## 进阶（结构 / 读者 / 目的）

4. 从【前文语气】到「【引文】」，语气转为【新语气】；这一转变通过【手法/句式】实现，推动读者【重新评估……】。  
5. 针对【目标读者】，作者借助【手法】（见「【引文】」）以【说服策略】强化【目的】。  
6. 若将「【引文】」中的【手法】去掉，【原有效果】会减弱，可见该选择服务于【整体意图】。  

## 比较与评价（可选解锁）

7. 与【另一处引文】相比，此处的【手法】更侧重于【差异化效果】，共同建构了【主题】。  
8. 【手法】在此处是有效的，因为它【具体理由】；但其局限在于【可能的误读/排他性】。  

## 使用说明（给实现者）

- 插入时保留【】，用轻微样式提示学生替换  
- 每次插入同时在侧栏提示：还缺证据 / 还缺效果？  
- 不要自动填满槽位；可提供「从已有批注填入引文」按钮单独填充【引文】
