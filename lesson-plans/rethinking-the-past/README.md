# 《Rethinking the Past》雅思阅读教案包

基于 IELTS Reading Passage 3（Cambridge IELTS 21 · Test 3：*Rethinking the Past*）编写。

## 文件说明

| 文件 | 用途 |
|------|------|
| [01-原文翻译与段落大意.md](./01-原文翻译与段落大意.md) | 全文翻译 + 段落大意 |
| [02-教案-学生版.md](./02-教案-学生版.md) | 学习目标、搭配、同义替换、做题步骤、答题纸 |
| [03-教案-老师版.md](./03-教案-老师版.md) | 课时流程、讲稿、练习答案、原题详解与答案速查 |

## 建议使用顺序

1. 师生先过 `01` 理解文意  
2. 学生用 `02` 上课与做题  
3. 教师按 `03` 计时授课并对照答案精讲
