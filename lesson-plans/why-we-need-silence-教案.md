## 二、篇章地图（先结构，后细节）

上课先让学生 **60 秒扫段落首句**，标出每段“干什么”，再做题。

| 段 | 核心功能（中文提示） | 定位锚点 |
|----|----------------------|----------|
| **A** | 噪声如何触发生理反应，长期危害健康 | blood pressure / fight or flight / cardiovascular |
| **B** | 噪声问题有多严重（数据 + WHO） | 40 decibels / 1 in 5 / Nick Antonio |
| **C** | 城市如何降噪（具体措施） | London / road coatings / leaf blowers / Antonio |
| **D** | 漂浮舱简介 + 感官剥夺时大脑“填空” | flotation tank / Feinstein / fill the void |
| **E** | 漂浮舱实验证据（问卷 + 脑扫描） | 50 people / questionnaire / DMN / depression |
| **F** | 沉默疗法 + **必须自愿** | Ben-Soussan / volition / distressing |
| **G** | 日常可实践：不必绝对静音；短时高频更好 | Pfeifer / outdoor garden / few minutes |

**教学口诀：** Matching Information 看**信息类型**；Summary 盯**数字/专名**；Matching People 先**找人名**再比改写。

## 三、同义词替换工作坊（核心）

> 原则：**IELTS 几乎从不原词照抄**。先圈题干关键词 → 预判替换 → 回文定位。

### 3.1 Q14–17 Matching Information：信息类型 + 同义改写

| 题号 | 题干关键词 | 同义/改写方向 | 原文锚点 | 答案 |
|------|------------|---------------|----------|------|
| **14** | examples of **strategies** to **decrease** noise the **public** are **exposed to** | strategies→measures/solutions；decrease→reduce/turn down/muffle；exposed to→living with/subjected to | C：quieter buses, road coatings, greenery, leaf blower ban, vehicle fines | **C** |
| **15** | **data** indicating the **extent** of **excessive** noise | data→figures/statistics；extent→how widespread；excessive→harmful levels | B：40 decibels；at least 1 in 5 people | **B** |
| **16** | **physiological changes** when we hear **sudden** noises | physiological→blood pressure / muscles / hormones；sudden→loud or unexpected | A：blood pressure goes up, muscles tense, glands release hormones | **A** |
| **17** | **relatively quiet** more **beneficial** than **totally silent** | relatively quiet→outdoor garden；totally silent→completely silent room；beneficial→more relaxation | G：garden vs completely silent room | **G** |

**课堂练习（2′）：** 遮住答案列，学生只说“我会在哪一段找什么信号词”。

---

### 3.2 Q18–21 Summary：题干改写 → 原文原词填空

> Summary 题干常改写，**空格答案必须是原文原词**（ONE WORD ONLY）。

| 题号 | Summary 说法 | 原文说法（同义替换） | 答案 |
|------|--------------|----------------------|------|
| **18** | concentrate on their own ____ → relax / meditate | focus on the **breath** → relaxed or **meditative** state | **breath** |
| **19** | given a ____ to complete before and after | answer a **questionnaire** prior to and following | **questionnaire** |
| **20** | improved general ____ | increase in … overall **wellbeing** | **wellbeing** |
| **21** | decreased activity … associated with ____ | DMN … linked with **depression** | **depression** |

**词性预判口诀（必讲）：**

- 18：their own + **名词**（身体/自我相关）
- 19：given a + **可数名词单数** + to complete → 研究工具
- 20：general + **抽象名词**（状态）
- 21：associated with + **名词**（疾病/心理状态）

**高频 Summary 同义对（板书）：**

| 题干 | 原文 |
|------|------|
| concentrate on | focus on |
| before and after | prior to and following |
| conducted an experiment | recruited … / investigate |
| reduction in | decreases in |
| associated with | linked with |
| suffering from stress | conditions related to stress |

### 3.3 Q22–26 Matching People：观点改写对照表

| 题号 | 题干压缩 | 同义替换链 | 人物 | 答案 |
|------|----------|------------|------|------|
| **22** | silent environment **against their will** → unpleasant | against their will ≈ do not want；unpleasant ≈ **distressing** | Ben-Soussan | **C** |
| **23** | quieter urban locations **likely to increase** | trend ≈ much more of this；coming years ≈ **in the future** | Antonio | **A** |
| **24** | senses **deprived of input** → mind creates **illusion** of images/sounds | deprived ≈ don’t have external sensory stimuli；illusion ≈ humming / visual effects；brain **fill the void** | Feinstein | **B** |
| **25** | **short** silent time → **positive impact** | short ≈ few minutes；positive impact ≈ make a **big difference** / gain benefits | Pfeifer | **D** |

## 四、重点搭配 Highlight（建议彩色标注）

按主题分组，要求学生：**朗读 → 划线 → 各造 1 句**。

### 4.1 噪声与健康

| 搭配 | 中文义 | 例句骨架 |
|------|--------|----------|
| **finely attuned to** | 对…高度敏感 | Humans are finely attuned to noise. |
| **from an evolutionary perspective** | 从进化角度看 | From an evolutionary perspective, … |
| **in response to** | 对…作出反应 | Chemistry alters in response to noise. |
| **fight or flight** | 战斗或逃跑反应 | Hormones prepare us for fight or flight. |
| **exposed to** (+ noise / levels) | 暴露于 | exposed to more than 40 decibels |
| **lead to** (+ health issues) | 导致 | can lead to cardiovascular disease |
| **a multitude of** | 大量的 | a multitude of health issues |
| **underestimated threat** | 被低估的威胁 | designated as an underestimated threat |
| **harmful to health** | 有害健康 | levels considered harmful to health |

### 4.2 城市降噪与政策

| 搭配 | 中文义 |
|------|--------|
| **turn the volume down** | 降低音量/噪声 |
| **provide recommendations for** | 提出建议 |
| **noise-reducing** (+ road coatings) | 降噪的 |
| **muffle sound** | 减弱/消弭声音 |
| **come into effect** | 生效 |
| **legislation has been approved** | 立法已获通过 |
| **see the benefits of** | 看到…的好处 |

### 4.3 漂浮舱 / 感官与大脑

| 搭配 | 中文义 |
|------|--------|
| **seek to understand** | 试图理解 |
| **beneficial to** | 对…有益 |
| **detract from the benefits** | 减损益处 |
| **sensory stimuli** | 感官刺激 |
| **fill the void** | 填补空白 |
| **focus on the breath** | 专注呼吸 |
| **meditative state** | 冥想状态 |
| **therapeutic tool** | 治疗工具 |
| **related to stress** | 与压力相关 |
| **prior to / following** | 在…之前/之后 |
| **decreases in … alongside an increase in** | …下降，同时…上升 |
| **linked with / associated with** | 与…相关 |
| **get out of balance** | 失衡 |
| **reset the nervous system** | 重置神经系统 |

### 4.4 沉默与日常实践

| 搭配 | 中文义 |
|------|--------|
| **advocate of** | …的倡导者 |
| **aware of** | 意识到 |
| **adequate response** | 恰当回应 |
| **benefit from** | 从…获益 |
| **to the same extent** | 达到同等程度 |
| **heightened state of stress** | 高度压力状态 |
| **calm down** | 平静下来 |
| **attainable in everyday life** | 日常生活中可获得 |
| **compared with** | 与…相比 |
| **gain benefits** | 获得益处 |
| **make a big difference** | 产生很大影响 |

**搭配小测（口头，3′）：** 老师说中文，学生回英文搭配（如：“暴露于噪声”→ *exposed to noise*）。

## 五、做题技巧（按题型流程）

### 5.1 Matching Information（Q14–17）

```
① 读题干 → 判断信息类型
   · examples of…     → 找具体措施/例子
   · data indicating… → 找数字、比例、分贝
   · a description of…→ 找过程/身体反应细节
   · evidence that…   → 找研究结论/对比结果
② 圈 2–3 个“不可替换核心词”，想出同义说法
③ 回文扫段（可乱序；一段可不用、不可复用需看题目说明——本题每题一段）
④ 定位后用整句验证，避免只见单词
```

**易错点：** Q16 别被 C 段“降噪措施”带跑——题干要的是**生理变化**，在 A。

### 5.2 Summary Completion（Q18–21）

```
① 读标题 Flotation Tanks → 锁定 D–E
② 每空先判词性 + 单复数
③ 用专名/数字当 GPS：Feinstein / 50 / 48 / 90 minutes
④ 填入后检查：语法通顺 + 必须原文原词 + 仅一词
```

**易错点：**

- 18 易填 *eyes / blinking* → 文意是 **focus on the breath** 才导向冥想
- 21 易填 *DMN / network* → 题干是 associated with **抑郁**，答案是 **depression**

### 5.3 Matching Features / People（Q22–26）

```
① 先在文中用荧光笔标出四个人名出现的位置
② 读陈述 → 压缩成“态度/结论”一句话
③ 人名段落内找同义改写，而非找原词
④ 注意 NB：一人可对应多题；做完数一下字母分布
```

**人物速记卡：**

| 人物 | 标签 |
|------|------|
| A Nick Antonio | 声学顾问；城市降噪；未来会更多 |
| B Justin Feinstein | 漂浮舱；大脑填空；DMN/抑郁 |
| C Tal Dotan Ben-Soussan | 内外皆静；必须自愿，否则痛苦 |
| D Eric Pfeifer | 花园>绝对静音；短时高频更有效 |

## 六、课堂活动设计

### Activity 1｜同义替换配对（10′）

发给学生两列卡片，限时配对：

| Column A（题干侧） | Column B（原文侧） |
|--------------------|--------------------|
| decrease the noise | turn the volume down / muffles sound |
| physiological changes | blood pressure goes up; muscles tense |
| data / extent | 40 decibels; 1 in 5 people |
| against their will | do not want; volition |
| deprived of input | don’t have external sensory stimuli |
| short amount of time | a few minutes at a time |
| more conscious of | more aware of |
| positive impact | make a big difference |

### Activity 2｜段落功能闪电答（5′）

老师念题干（如 “Who talks about leaf blowers?”），学生举牌说段落字母。

### Activity 3｜限时模考（25′）

- 建议计时：**14–17（7′）→ 18–21（8′）→ 22–26（10′）**
- 做完对答案，只讲**替换链**，不逐句翻译全文。
