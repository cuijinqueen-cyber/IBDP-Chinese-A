## 三、同义词替换工作坊

### 3.1 Q14–19 Matching Information

| 题 | 题干关键词 | 同义/改写 | 原文锚点 | 答案 |
|----|------------|-----------|----------|------|
| **14** | **uncertainty** / **purpose** of objects | uncertainty→not known；purpose→function | E：precise function is not known | **E** |
| **15** | **climatic factor** increased **problems** | climatic→droughts；increased problems→crisis point | G：series of droughts | **G** |
| **16** | **location** where **king’s family** lived | family→male relatives；lived→residences | C：grander residences… male relatives of the king | **C** |
| **17** | people who brought goods **by ship** | by ship→by sea；people→merchants | D：merchants travelling from India by sea | **D** |
| **18** | **estimate** of **size** community grew | estimate→around；size→population | B：around 5,000 people | **B** |
| **19** | **agricultural produce** **exchanged** | produce→farming surplus；exchanged→traded | A：surplus that could be traded for needed goods | **A** |

### 3.2 Q20–21 Multiple Choice（选两项）

| 选项 | 判断 | 依据 |
|------|------|------|
| A 并非人人用金作支付 | ✗ | 文说 intrinsic value ≠ currency，未说“并非人人” |
| **B** 金器放在国王墓葬附近 | **✓** | found at the **royal burial site** |
| C 最贵重是金权杖 | ✗ | 仅说 may have been a sceptre，无“most valuable” |
| **D** 金饰做法也见于另一王国 | **✓** | found nowhere else except **Great Zimbabwe** |
| E 金工是受人尊敬职业 | ✗ | 未提及 |

**答案：B + D**（顺序不限）

### 3.3 Q22–26 Summary（ONE WORD）

| 题 | Summary 说法 | 原文说法 | 答案 |
|----|--------------|----------|------|
| **22** | community’s ____ indicated by pottery | indicator of the **prosperity** | **prosperity** |
| **23** | round ceramic objects, ____ and animal figures | ceramic discs, and **whistles** | **whistles** |
| **24** | people with stretched ____ | elongated **bodies** | **bodies** |
| **25** | ceremonies to honour ____ | offerings to **ancestors** | **ancestors** |
| **26** | pieces of ____ from a local metal | **jewellery** … locally sourced copper | **jewellery** |

**词性预判：** 22 抽象名词｜23 复数名词｜24 复数身体部位｜25 复数名词｜26 不可数/集合名词

## 四、重点搭配 Highlight

### 地理与社会

| 搭配 | 义 |
|------|----|
| **flourished between** | 在…期间繁荣 |
| **easily defended** | 易于防守 |
| **due to its inaccessibility** | 因其难以接近 |
| **cattle herding** | 放牧 |
| **source of political power** | 政治权力来源 |
| **at its peak** | 在鼎盛期 |
| **stone enclosure** | 石砌围场 |
| **mud and thatch housing** | 泥草屋 |

### 贸易与权力

| 搭配 | 义 |
|------|----|
| **traded for** | 换取 |
| **locally-sourced** | 本地产的 |
| **strengthening of political authority** | 强化政治权威 |
| **monopolise** … **connections** | 垄断联系 |
| **lucrative** interregional connections | 有利可图的跨区域联系 |
| **in decline** | 衰落中 |
| **place … stress on** | 给…带来压力 |
| **brought to a crisis point** | 推至危机点 |

### 考古发现

| 搭配 | 义 |
|------|----|
| **archaeological record / discoveries** | 考古记录/发现 |
| **indicator of** | …的指标 |
| **precise function is not known** | 确切功能未知 |
| **royal burial site** | 王室墓葬 |
| **intrinsic value** | 内在价值 |
| **as opposed to** | 与…相对 |

## 五、做题技巧

### Matching Information（14–19）
```
① 标信息类型：uncertainty / likelihood / location / reference / estimate / mention
② 预判同义（climatic→drought；by ship→by sea；exchanged→traded）
③ 数字与专名优先扫：5,000 / India / Great Zimbabwe / droughts
④ 整句验证，避免只见单词
```

### Multiple Choice TWO（20–21）
```
① 先读完全部选项，再回 F 段
② 警惕绝对词：most / everyone / only
③ 正确项常是同义改写，而非原词照抄
④ 选两项后互相核对，排除“推断过度”
```

### Summary（22–26）
```
① 标题 Archaeological discoveries → 锁定 E 段
② 先判词性；列表结构帮助找 23
③ stretched ____ ← elongated bodies
④ honour ____ ← offerings to ancestors
⑤ local metal ← locally sourced copper → 答案是 jewellery 不是 copper
```
