# 《草原》MYP 教学资源

统编版六年级上册第 1 课《草原》（老舍）的 MYP 教学设计与互动网页。

## 用网页打开

```bash
python3 -m http.server 8090
```

浏览器访问：**http://localhost:8090/caoyuan.html**

## 文件

| 文件 | 说明 |
|------|------|
| `caoyuan.html` | 互动探究网页（推荐上课使用） |
| `lessons/草原_MYP教案.md` | 完整教案 |
| `ppt/草原_MYP教案课件.pptx` | 16 页课堂课件 |

## MYP 要点

- **全球背景**：身份认同与人际关系
- **关键概念**：联系
- **相关概念**：场景、风格、主题
