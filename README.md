# 文脉 · IBDP 文学精读工坊

面向 **IBDP 中文 A · 文学** 的交互学习站：培养学生**精读、主题理解与诠释**能力，贯穿课程**七大概念**，并以三层练习循序推进。

## 启动

```bash
# 任意静态服务器均可，例如：
python3 -m http.server 8080
```

打开 http://localhost:8080/

## 学习设计

### 七大概念（独立色标）

身份 · 文化 · 创造力 · 沟通 · 视角 · 转变 · 再现  

首页概念卡可点击筛选原文相关标注；侧栏可切换「手法色标 / 概念色标」图例。

### 三层练习

| 层级 | 目标 | 活动 |
|------|------|------|
| **01 识别手法** | 看见并命名 | 多选清单 + 句子手法选择 |
| **02 分析效果** | 阐释作用 | 效果选择题，并标注通向的概念 |
| **03 撰写诠释** | 写成分析段 | 题干 + 句式支架 + 证据库 + 自评量规 |

原文支持「按手法着色 / 按概念着色 / 纯文本」三种精读模式。

## 教学文本

白先勇《永远的尹雪艳》（教学示例选段）。可在 `js/data.js` 中替换文本、锚点、练习与范文。

## 文件结构

- `index.html` — 学生端主界面
- `css/styles.css` — 样式与色标
- `js/data.js` — 概念、手法、文本与三层练习数据
- `js/app.js` — 交互逻辑
