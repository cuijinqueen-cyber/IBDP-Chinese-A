# 竹节人 · 从阅读到写作

面向六年级 PYP 中文第一课的互动网页：以统编版课文《竹节人》为素材，引导学生**从阅读中学习写作**。

## 本地打开

```bash
# 任意静态服务器均可，例如：
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080`。

或直接用浏览器打开 `index.html`（部分浏览器对本地字体加载可能有限制，推荐用本地服务器）。

## 课程结构（对应 PYP 探究）

1. **想一想** — Tuning in：激活童年游戏经验  
2. **读故事** — Finding out：三幕互动阅读 + 选择式思考题  
3. **词语猎人** — Sorting out：点击生动词语收入词库 + 心情翻转  
4. **写作工坊** — Going further：句架支架、词库插入、成功标准自检  
5. **反思与行动** — Reflection：自评 + 课后采访行动  

学习足迹可保存在浏览器 `localStorage`。

## 教学课件（PPT）

路径：`ppt/竹节人_原文与教案.pptx`（14 页）

内容包含：
- 学习目标与 PYP 框架
- 原文三幕导读 + 课堂节选（请对照课本读全文）
- 60 分钟教案流程与细案
- 词语猎人 / 写作量规 / 课后行动

重新生成：

```bash
python3 scripts/generate_ppt.py
```

## 设计说明

- 听说优势学生：先口头复述、选择题探究，再进入写作  
- 读写提升：词语收集 → 句架 → 成功标准，降低动笔门槛
