# Cambridge IELTS 21 · Academic Test 4 教案

本仓库提供《剑桥雅思21》学术版 **Test 4** 听力和阅读详细教案网页，适合课堂教学与自学复盘。

## 打开方式

直接在浏览器打开：

```bash
open ielts21-test4-lesson/index.html
```

或用本地静态服务：

```bash
cd ielts21-test4-lesson
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 内容结构

- 课程总览与题型地图
- 听力 Part 1–4：场景、策略、答案精讲、课堂活动
- 阅读 Passage 1–3：主线、题型、答案精讲、易错点
- 答案速查表
- 课后练习与自评建议
