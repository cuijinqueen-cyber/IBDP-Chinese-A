# 《草原》MYP 教学资源

统编版六年级上册第 1 课《草原》（老舍）的 MYP 教学设计。

## 文件

| 文件 | 说明 |
|------|------|
| `lessons/草原_MYP教案.md` | 完整教案（框架、两课时流程、评估、行动） |
| `ppt/草原_MYP教案课件.pptx` | 12 页课堂课件 |
| `scripts/generate_caoyuan_ppt.py` | 课件生成脚本 |

## MYP 要点速览

- **全球背景**：身份认同与人际关系  
- **关键概念**：联系  
- **相关概念**：场景、风格、主题  
- **探究声明**：文学作品通过描绘地方与相遇，揭示文化身份如何在联系中被理解与深化。

## 重新生成课件

```bash
pip install python-pptx
python3 scripts/generate_caoyuan_ppt.py
```
