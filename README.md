# 文脉 · IBDP 中文 A 精读工坊

基于谢宗玉《英语老师》的交互练习网页，面向 IBDP 中文 A 语言与文学课程，分层训练：

1. **精读** — 冲突、情感轨迹、关键信息
2. **辨法** — 文学手法识别与配对
3. **析写** — IB 式分析写作脚手架与自评

## 使用

直接用浏览器打开 `index.html`，或本地起一个静态服务：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 文本说明

练习文本取自谢宗玉《英语老师》（《在往事中成长》），对应 IB Chinese A1 Paper 1 选文示例结构。
