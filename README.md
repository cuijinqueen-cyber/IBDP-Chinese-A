# 文脉 · IBDP 中文 A 互动学习平台

基于谢宗玉《英语老师》的五层互动练习平台，面向 IBDP 中文 A 语言与文学。

## 五层路径

1. **识别文学手法** — 勾选文中手法 + 句子辨识
2. **彩色精读标注** — 不同手法用不同颜色在原文中标注
3. **深入思考** — 人物、视角、意象、伦理与 IB 全局问题
4. **写作大纲** — 对照 Paper 1 标准 A–D 搭建大纲
5. **写作提交** — AI 初评（本地量规引擎）→ 教师复审台二次审核

## 使用

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

- 左侧填写学习者姓名后开始练习
- 教师复审入口通行码默认：`ibdp2026`（可在 `js/data.js` 的 `APP.teacherPin` 修改）

## 说明

- 进度、标注、思考、大纲、作文与提交记录保存在浏览器 `localStorage`
- AI 初评为基于 IB 量规关键词/结构/引文命中的规则引擎，便于课堂演示与即时反馈；正式成绩以教师复审为准
- 教师可在复审台查看提交、调整分数、撰写评语，并导出 JSON
