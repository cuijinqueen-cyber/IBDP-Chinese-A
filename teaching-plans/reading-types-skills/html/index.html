雅思阅读题型做题技巧总览教案

对象： Band 6.5 → 7.0–7.5

目标： 识别题型 → 套用固定流程 → 用真题练定位与排除

材料来源： Cambridge 风格 Test 3（Saiga / Dar es Salaam / Rethinking the Past）+ 真经 TFNG（Self-esteem / Gilbert）

0. 一页题型地图

题型核心技能顺序性高发失分
True/False/Not Given证据句比对基本有序比较词、多写信息
Yes/No/Not Given作者观点比对基本有序把他人观点当作者观点
Notes / Summary / Table 填空词性预测 + 原词抄写通常有序自造同义词
Sentence completion同上通常有序超词数
Short-answer问什么答什么通常有序答非所问
Multiple choice目的/细节排除常有序被细节选项诱惑
Matching headings段落大意无序抓细节当主旨
Matching information细节定位到段无序扫太粗
Matching features/names人名/类别锚点无序张冠李戴
Matching sentence endings半句语义+语法常有序只看语法通顺
Diagram / Flowchart 标注图序=文序有序漏步骤

总原则（先教）：

  1. 1. 先看题型指令（尤其 ONE WORD / NO MORE THAN TWO WORDS）。
  2. 2. 先划题干定位词（专有名词、数字、极端词、比较词）。
  3. 3. 答案必须回到原文句子，不凭段落印象。
  4. 4. 填空抄原文词；判断题比对逻辑，不比对“感觉像”。

1. 通用做题流程（每课开场 10 分钟）


① 读标题/副标题 → 预测文本类型（说明 / 问题-解决 / 论说文）
② 扫每段首句 → 画段落地图（1 分钟）
③ 看题型块 → 决定先做哪块（填空常优先，因有序好定位）
④ 逐题：定位词 → 扫描 → 精读一句/两句 → 作答
⑤ 不确定先标 ?，全篇结束后回查

时间盒（Academic 60 分钟）建议

  • Passage 1：18 分钟
  • Passage 2：20 分钟
  • Passage 3：22 分钟
  • 留 0 分钟涂卡习惯：边做边填

第一部分：判断类

2. TRUE / FALSE / NOT GIVEN

做题技巧

  1. 1. 圈题干中的：绝对词（all, only, evenly）、比较（more than）、数量（most）、因果（lead to）。
  2. 2. 定位后精读，问三句：

- 同义改写？→ TRUE

- 明确相反？→ FALSE

- 提到话题但缺该点？→ NOT GIVEN

  1. 3. FALSE 必须“原文能打脸”；NG 是“原文没说够”。

必避错误

  • ❌ 用背景知识判断
  • ❌ 看到同一主题就选 TRUE
  • ❌ 把“未比较”当成 FALSE

3. YES / NO / NOT GIVEN（作者观点）

与 T/F/NG 的差别

  • T/F/NG：事实是否一致
  • Y/N/NG：是否符合 writer’s claims/views

做题技巧

  1. 1. 分清：作者观点 vs 报告/他人观点。
  2. 2. 态度词：inclined to, little to indicate, cast doubt, incorrectly。
  3. 3. 题干若写 “the report asserted…”——对的是报告内容，不是作者赞同与否。

第二部分：填空类

4. Notes / Summary / Table Completion

做题技巧

  1. 1. 读小标题 → 锁定段落带。
  2. 2. 空前空后定 词性（名词复数？不可数？）。
  3. 3. 扫描同义表达，抄原文原词（除非指令允许改写，雅思几乎都要求来自原文）。
  4. 4. 遵守字数：ONE WORD ONLY / NO MORE THAN TWO WORDS。

必避错误

  • ❌ 自己写同义词（dust→dirt）
  • ❌ 单复数错误（horn/horns）
  • ❌ 无视小标题导致窜段

真题精析（DART Notes 19–26）

Features： lanes → boarding → wheelchairs

Problems： fuel → flood → smartcards → gates → queues

技巧：小标题 Features/Problems 直接决定搜索区；先功能设计后运营故障。

5. Sentence Completion / Short Answers

技巧

  • Sentence completion：语法通顺 + 原词。
  • Short answer：问 where/when/how many 就答对应信息，不加整句。

必避

  • 超过词数；把答案写成完整句子（除非要求）。

第三部分：匹配类

6. Matching Headings（段落标题）

做题技巧

  1. 1. 先读所有 headings，划主题词。
  2. 2. 每段读首句+末句，中间扫转折（however, yet）。
  3. 3. 选“整段功能”，不选“某句亮点细节”。
  4. 4. 先做有把握段，缩小选项池。

必避

  • ❌ 看到数字/例子就选含该细节的标题
  • ❌ 标题与段首同词就秒选（常是干扰）

课堂微例（问题-解决型文章）

段若先写 congestion，后写 BRT 方案 → 标题应是 A transport solution for…，不是 Causes of urban growth（即便段内提了增长）。

7. Matching Information（哪段包含信息）

技巧

  • 题干是细节/例子/原因 → 用独特名词扫描全文。
  • 可与 NB: you may use any letter more than once 有关——允许一段多用。

必避

  • 只读首句就判段；信息常在段中例子里。

8. Matching Features / Names（人物/分类匹配）

技巧

  1. 1. 先在文中把所有人名/分类 下划线标出。
  2. 2. 题干逐条定位到该人附近句子。
  3. 3. 注意：一人可对应多题；有的选项不用。

真题关联

Gilbert 篇若出匹配题，应把 Columbus / Chinese / Maxwell / Galileo 先标好再做，避免 Odyssey 与 Columbus 传说混淆。

9. Matching Sentence Endings

技巧

  1. 1. 用题干专有名词定位（Kalambo Falls, June 2023…）。
  2. 2. 读完整观点后再选结尾。
  3. 3. 最后检查：整句语法 + 逻辑。

10. Multiple Choice（单选）

技巧分层

问法策略

The writer’s purpose in paragraph X…看段落功能，不看某细节
Which of the following…排除绝对项/未提及项

11. Diagram / Flowchart Labelling

技巧

  • 图上已有词 = 定位工具。
  • 流程题答案顺序常跟箭头一致。
  • 注意被动描述：is filtered / is stored。

必避

  • 跳步填空；忽略图例单位。

第五部分：篇章策略与课程序列

12. 三种篇章的阅读策略

篇章类型代表先看什么
问题→解决Saiga / Dar问题链、方案、残留问题
时间/传记Gilbert时间线与“谁先发现”
学术论说Rethinking the Past / Self-esteem旧假设→证据→作者态度

转到写作的彩蛋： Dar 篇“方案不完美”结构，可直接迁移到大作文 Problem-Solution 的评价段。

17. 教师示范课脚本（30 分钟微型课）

材料： Saiga Q8 + Q11

目标： 当场分清 FALSE 与 NG

  1. 1. 学生先独立做两题（4）
  2. 2. 揭示：Q8 有分布数据打脸 evenly → FALSE（8）
  3. 3. 揭示：Q11 有气候威胁但无“比世界其他地方更…”→ NG（8）
  4. 4. 学生用自己的话写出区别公式（5）
  5. 5. 再做 Self-esteem Q8（成人 vs 学生更幸福）巩固假比较 = NG（5）

18. 附录：题型判定与优先顺序口诀


有序填空先下手，数字人名好定位；
判断先圈极端词，比较因果最易坑；
标题只抓段落用，选择先问在问啥；
匹配先标锚点名，抄词永远胜过猜。
