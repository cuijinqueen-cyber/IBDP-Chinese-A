2. Master problem-solving toolkit (teach once, reuse always)

2.1 Before reading questions deeply

  1. Read title → predict topic.
  2. Skim paragraph first sentences → build a paragraph map.
  3. Mark text type: description / chronology / problem-solution / argument.

2.2 Notes / Summary completion (ONE WORD ONLY)

  1. Read the note title + subheadings (they show which paragraphs to search).
  2. Predict grammar: noun? plural? uncountable?
  3. Underline keywords around the blank.
  4. Scan passage for paraphrase of those keywords.
  5. Copy exact word from passage (no synonyms of your own).
  6. Check: singular/plural and spelling.

2.3 TRUE / FALSE / NOT GIVEN

  1. Underline absolute / comparison / quantity words (evenly, most, more than, significant).
  2. Locate the relevant sentence.
  3. Decide:
  • TRUE = same meaning (paraphrase OK)
  • FALSE = passage says the opposite
  • NOT GIVEN = point not addressed (often a missing comparison or extra claim)

2.4 YES / NO / NOT GIVEN (Passage 3)

Same logic as T/F/NG, but about writer’s views, not just facts.

2.5 Multiple choice (writer’s purpose)

  1. Read question stem carefully (What is the writer doing…?).
  2. Re-read the named paragraph.
  3. Eliminate options that are too narrow, too extreme, or not in that paragraph.

2.6 Matching sentence endings

  1. Scan for unique anchors (place names, dates, species).
  2. Read the full idea around the anchor.
  3. Match meaning, then confirm grammar of the completed sentence.

Problem-solving approach inside the passage (meta-teaching)

  1. Identify old problem/assumption: e.g. only Homo sapiens did complex work; men were hunters/leaders.
  2. Bring new evidence: dated artefacts, meta-analysis, protein analysis.
  3. Challenge methods/bias: measurable brain size; patriarchal research lenses.
  4. Offer revised conclusion: more complex, less inevitable inequality.

This is ideal for teaching students how academic Reading Passage 3 arguments move.

7.2 Difficulty profile

  • Harder vocabulary + abstract ideas
  • Questions test writer purpose and attitude, not only facts
  • Y/N/NG requires separating writer view from mentioned claims of others

Solver routine for purpose MCQs

  1. Ignore attractive detail options.
  2. Ask: Is the writer describing, arguing, exemplifying, or concluding?
  3. Match option verb (pinpointing / outlining / summarising).

10. Lesson procedures (detailed)

Lesson 1 — Passage 1 map + Notes 1–7 (90 min)

  1. Predict from title (5)
  2. Paragraph mapping in pairs (15)
  3. Teach Notes routine (10)
  4. Guided Q1–3 (15)
  5. Independent Q4–7 (20)
  6. Error autopsy: synonym temptation (15)
  7. Homework: rewrite wrong answers with evidence line numbers/phrases

Lesson 2 — Passage 1 T/F/NG (90 min)

  1. Mini-lesson FALSE vs NG with invented examples (15)
  2. Timed Q8–13 (18)
  3. Evidence board: quote + decision (30)
  4. Make 3 student-written trap statements for peers (20)
  5. Reflection checklist (7)

Lesson 3 — Passage 2 problem–solution map (90 min)

  1. Build problem tree on board (20)
  2. Identify solution choice and why not metro (15)
  3. T/F/NG 14–18 timed (15)
  4. Deep review focusing on Q15/Q18 quantifiers (25)
  5. Link to Writing: 5-sentence oral summary of problems/solution (15)

Lesson 4 — DART notes + evaluating solutions (90 min)

  1. Separate “design features” vs “implementation problems” (15)
  2. Notes 19–26 (25)
  3. Discuss: Is DART a success, partial success, or failing? Cite text (25)
  4. Language upgrade: capacity, designated lanes, stakeholders (15)
  5. Homework paragraph: evaluate one solution with one remaining problem

Lesson 5 — Passage 3 argument + MCQ (90 min)

  1. Trace argument moves 1–10 (20)
  2. Teach purpose verbs (10)
  3. Q27–30 process talk-aloud (30)
  4. Analogy analysis (mobile phones) (15)
  5. Vocabulary: preconceptions, incremental, meta-analysis (15)

Lesson 6 — Matching + Y/N/NG + synthesis (90 min)

  1. Anchor scanning drill for 31–34 (20)
  2. Y/N/NG 35–40 (25)
  3. Full mixed review quiz from all 3 passages (25)
  4. Personal error profile (FC of reading: timing, traps, vocab) (20)
