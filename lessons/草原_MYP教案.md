# 《草原》MYP 语文教学设计

**教材**：统编版六年级上册 · 第一单元第 1 课  
**作者**：老舍  
**适用对象**：六年级（MYP Year 1）中国学生；听说较强，读写待提升  
**课时**：2 课时（每课时约 40–45 分钟；也可整合为 90 分钟探究课）  
**学科**：语言与文学（Language and Literature）

---

## 一、MYP 单元框架（先见森林，再见树木）

| 项目 | 设计 |
|------|------|
| **全球背景 Global Context** | **身份认同与人际关系（Identities and relationships）** |
| **探索焦点** | 身份、归属、友谊、跨文化理解；“他乡相遇如何成为心灵相连” |
| **关键概念 Key Concept** | **联系（Connections）** |
| **相关概念 Related Concepts** | **场景（Setting）**、**风格（Style）**、**主题（Theme）** |
| **探究声明 Statement of Inquiry** | **文学作品通过描绘地方与相遇，揭示文化身份如何在联系中被理解与深化。** |
| **ATL 技能** | 沟通（细读与口头表达）、研究（提取信息）、思考（比较与迁移）、社交（换位思考） |
| **学习者培养目标** | 心胸开阔、善于交流、富有爱心、反思者 |

### 全球背景如何“渗入”课堂（而非贴标签）

1. **开课就抛出全球背景问题**：不同民族/文化的人初次相遇，靠什么建立信任？  
2. **读文时不断回扣**：草原不仅是风景，也是“关系发生的地方”。  
3. **写作迁移**：写一次“跨群体的温暖相遇”（班级、社区、旅行、线上均可）。  
4. **行动延伸**：采访一位“来自不同地方/文化背景的人”，记录一句让自己感动的话。

> 教师用语建议：少说“今天学全球背景”，多问“这段文字让你想到现实中哪些‘人与人的桥梁’？”

---

## 二、探究问题 Inquiry Questions

| 类型 | 问题 |
|------|------|
| **事实性 Factual** | 课文写了哪些风景？按什么顺序写了哪些人事活动？ |
| **概念性 Conceptual** | 作者如何用语言把“景美”和“情美”联系起来？“地方”如何影响人的感受与关系？ |
| **辩论性 Debatable** | “真正的友谊是否一定需要共同的语言与相同的文化背景？” |

---

## 三、学习目标与成功标准

### 学习目标

1. **知识**：理清“风光描写 → 迎客—相见—款待—联欢—话别”的结构；积累重点词语。  
2. **概念**：理解 **联系**：景物、民俗、情感如何相互连接；理解 **身份与关系** 在跨民族交往中的意义。  
3. **技能**：品味比喻、拟人与情景交融；完成一次“相遇小记叙”的短写。  
4. **态度**：尊重多元文化，愿意用开放心态认识“不同”。

### 成功标准（对学生可见）

- 我能用自己的话概括课文“景”和“情”两部分。  
- 我能找出至少 3 处写出“美/热/亲”的语句，并说明方法。  
- 我能解释结尾诗句与全文的联系。  
- 我能写一段 100–150 字的“温暖相遇”短文，有具体动作与心情。  
- 我能用 1 句话回应全球背景问题：联系如何改变我们对他人的看法。

## 四、学情与差异化

| 学情 | 策略 |
|------|------|
| 听说强 | 多用口头复述、角色对话、辩论入口 |
| 读写弱 | 提供句架、词库、分段阅读任务单 |
| 对草原陌生 | 用图片/短视频建立“地方感”，再读文字 |
| 理解“民族团结”易口号化 | 拉回具体场面：怎么迎、怎么待、怎么别 |

## 五、课时一（约 40–45 分钟）  
### 主题：地方如何塑造感受——读出“景美”，看见“联系”的起点

### 1. Tuning in｜导入与全球背景激活（8′）

**活动：两张图，一个问题**  
- 出示：辽阔草原 / 城市街景（或教室日常）。  
- 问题：**一个地方，会怎样影响人的心情和待人方式？**  
- 学生用 30 秒口头分享。教师板书关键词：开阔、热情、拘束、匆忙……  

**点题**：今天读老舍《草原》。我们不仅看风景，更探究——  
**人们如何在一个地方相遇，并建立联系？**（全球背景：身份认同与人际关系）

### 2. Finding out｜初读建构（15′）

1. **听读/自读**全文（可分段）。  
2. **双栏笔记**：

| 我看见的“地方”（景） | 我看见的“人与关系”（情） |
|----------------------|---------------------------|
|                      |                           |

3. **结构拼图**（小组或师生共填）：  
   风光 → 迎客 → 相见 → 款待 → 联欢 → 话别  

**形成性评估**：能否指出“先景后人、由事及情”的顺序。

### 3. Sorting out｜精读风光段（15′）

**核心问题（概念性）**：作者用哪些语言策略，让读者“进入”草原？

推荐聚焦句（请对照课本原文细读）：
- “那里的天比别处的天更可爱……”  
- “一碧千里，而并不茫茫”  
- 羊群像“给无边的绿毯绣上了白色的大花”  
- “翠色欲流……轻轻流入云际”  
- 骏马大牛“静立不动，好像回味……”

**学习活动：颜色·线条·心情三色标注**
1. 圈出写颜色/形态的词。  
2. 标出修辞（比喻/拟人）。  
3. 写出作者心情词，并追问：景物与心情如何“联系”？

**对比朗读**：平淡改写句 vs 原文，体会风格（Related concept: Style）。

### 4. Reflection｜课时一出口（5–7′）

便利贴完成：  
**“如果草原会说话，它最想告诉客人一句什么？”**  
回扣：地方（Setting）如何参与“关系的发生”。

**课后微任务**：把风光段中最喜欢的一句抄下，并仿写一句家乡/校园景色。

## 六、课时二（约 40–45 分钟）  
### 主题：相遇如何建立联系——读出“情美”，迁移到真实世界

### 1. Tuning in｜回接（5′）

展示学生仿写；复习探究声明。  
今日重点：从“风景中的我”走向“关系中的我们”。

### 2. Finding out｜场面阅读（12′）

按事件链速读并完成表格：

| 场面 | 关键动作/细节 | 人物心情 | 体现的“联系” |
|------|----------------|----------|--------------|
| 迎客 |  |  |  |
| 相见 |  |  |  |
| 款待 |  |  |  |
| 联欢 |  |  |  |
| 话别 |  |  |  |

**特别关注**：  
- “像一条彩虹向我们飞过来”——视听与热情的结合  
- 主客从“稍感拘束”到融洽——关系如何变化（Change within Connections）

### 3. Sorting out｜主旨与全球背景深挖（10′）

聚焦结尾：  
**“蒙汉情深何忍别，天涯碧草话斜阳”**

三层追问：
1. **字面**：谁不忍别？在何处话别？  
2. **文本**：为何景（碧草斜阳）与情（蒙汉情深）必须写在一起？  
3. **全球背景**：跨越语言、习俗、地域的友谊，靠什么建立？可迁移到哪些当代情境？（移民家庭、国际学校、社区志愿者、旅行中的善意……）

**迷你辩论（辩论性探究，6–8′）**  
正方：共同文化更易建立友谊。  
反方：真诚行动比相同背景更重要。  
要求：必须引用课文一个细节作证据（ATL：沟通与批判性思考）。

### 4. Going further｜写作迁移（12–15′）

**任务**：《一次温暖的相遇》（100–150 字）

**句架支架**：
1. 在______，我遇到了______。  
2. 起初我觉得______；后来因为______（具体动作），我感到______。  
3. 这次相遇让我明白：联系往往开始于______。

**词库加油站（从课文迁移）**：  
热情、稍感拘束、会心、定要、敬酒、联欢、依依、话别……（鼓励学生转化为自己的生活词汇）

**成功标准快检**：有场合、有人物、有动作细节、有关系变化、有一句“联系”感悟。

### 5. Reflection & Action｜反思与行动（5′）

**反思三问**：
1. 我今天对“联系”有什么新理解？  
2. 写作时哪一步最难？  
3. 我能为身边“不同背景的人”做什么一件小事？

**行动（Action）**：  
采访家人或同学：讲一个“不同群体之间互相帮助”的真实故事，下节课用三句话分享。

## 七、评估设计（对接 MYP 语言与文学标准方向）

| 评估类型 | 任务 | 主要观察 |
|----------|------|----------|
| 形成性 | 双栏笔记、场面表、三色标注、辩论证据 | 理解、概念运用 |
| 总结性（微型） | 《一次温暖的相遇》短写 + 一句全球背景回应 | 组织、语言、主题意识 |
| 自评/互评 | 成功标准清单 | 反思者品质 |

### 简要量规（写作）

| 维度 | 达标 | 良好 | 优秀 |
|------|------|------|------|
| 组织 | 有起因与结果 | 相遇过程清楚 | 关系变化清晰可见 |
| 细节 | 1 处动作 | 2–3 处具体细节 | 动作+心情+场合融合 |
| 概念迁移 | 提到友好 | 点出“联系/理解” | 能连接课文与现实 |
| 语言 | 基本通顺 | 有生动动词/形容词 | 有课文写法的合理迁移 |

> 说明：若学校正式使用 MYP 标准，可对应：A 分析（赏析语句）、B 组织（结构表与作文组织）、C 创作文本（短写）、D 使用语言（词句准确性与风格意识）。本课以形成性与微型总结性为主。

## 十、教师课后反思提示

1. 学生是否把“民族团结”理解成具体可感的行为，而非空洞口号？  
2. 全球背景是自然贯穿，还是变成额外说教？  
3. 读写弱的学生是否借助句架完成了表达？下一步词汇或结构练什么？  
4. 辩论是否引用了文本证据？（概念探究的关键证据）

---

## 十一、一页纸“教师口播稿”（可直接上课）

> 同学们，今天我们进入老舍的《草原》。  
> MYP 的学习不只记住课文写了什么，更要带着**大概念**去读。  
> 本课的全球背景是**身份认同与人际关系**：不同文化背景的人，怎样相识、相知？  
> 关键概念是**联系**：风景与心情如何联系？主人与客人如何联系？课文与我们的生活如何联系？  
> 读完后，请你不只说“草原很美、蒙古族很热情”，还要能回答——  
> **是哪些具体的语言和行动，让‘不同’变成了‘亲近’？**  
> 最后，把这种方法用到你自己的写作里：写一次真实的温暖相遇。
