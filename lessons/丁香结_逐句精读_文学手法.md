# 《丁香结》逐句精读 · 文学手法标注

**课文**：统编版六年级上册第 2 课  
**作者**：宗璞  
**用途**：精读训练 / 课堂课件配套讲义  
**说明**：请对照课本全文；下文聚焦关键句与手法，不替代原书。

---

## 结构总览

| 部分 | 段落 | 内容 | 写法重心 |
|------|------|------|----------|
| 赏花 | 1–3 | 城里→城外→斗室 | 多角度描摹、由远及近 |
| 悟结 | 4–6 | 雨中丁香→结之由来→人生哲理 | 引用、象征、翻新立意 |

---

## 第1段｜城里丁香

### 句①
> ……忽然有一批雪白，顿使人眼前一亮，再仔细看，才知是两行丁香花。

| 手法 | 作用 |
|------|------|
| 设悬 / 延迟揭示 | 先写视觉冲击，后点出丁香 |
| 视觉描写 | “雪白”“眼前一亮”突出繁盛夺目 |

### 句②（金句）
> 有的宅院里探出半树银妆，星星般的小花缀满枝头，从墙上窥着行人，惹得人走过了还要回头望。

| 手法 | 作用 |
|------|------|
| 比喻（星星般） | 小巧、繁密、闪亮 |
| 拟人（探、窥） | 俏皮灵动，如有情态 |
| 侧面描写 | “回头望”写花之魅力 |
| 炼字（银妆） | 白而盛 |

---

## 第2段｜城外丁香

### 句①
> 月光下白的潇洒，紫的朦胧。

| 手法 | 作用 |
|------|------|
| 对举 | 白/紫两种气质对照 |
| 拟人式炼字（潇洒） | 白丁香自然大方 |
| 朦胧 | 紫丁香含蓄柔美 |

### 句②
> 还有淡淡的幽雅的甜香，非桂非兰，在夜色中也能让人分辨出，这是丁香。

| 手法 | 作用 |
|------|------|
| 嗅觉描写 | 补足感官层次 |
| 否定比较（非桂非兰） | 突出香气独特 |
| 品格暗示 | 淡雅清幽 |

---

## 第3段｜斗室丁香

### 句①
> 伏案时抬头便看见檐前积雪。……最先映入眼帘的，也是那一片莹白。

| 手法 | 作用 |
|------|------|
| 借代 / 借喻（积雪、莹白） | 突出白、盛、纯净、光洁 |
| 空间推进 | 花与“我”的生活最近，情更深 |

### 句②
> 那十字小白花，那样小，却不显得单薄。许多小花形成一簇，许多簇花开满一树，……照耀着我的文思和梦想。

| 手法 | 作用 |
|------|------|
| 层递（小花→簇→树） | 写繁盛过程 |
| 先抑后扬 | 小而不单薄 |
| “照耀”的移用 | 花成精神力量，近象征 |

---

## 第4段｜雨中丁香与古典意象

### 句①
> 古人词云：“芭蕉不展丁香结”“丁香空结雨中愁”。

| 手法 | 作用 |
|------|------|
| 引用典故 | 引入愁怨传统意象 |
| 铺垫 | 为后文“翻新”做准备 |

### 句②
> ……着了水滴的丁香格外妩媚。花墙边两株紫色的，如同印象派的画，线条模糊了，直向窗前的莹白渗过来……

| 手法 | 作用 |
|------|------|
| 比喻（印象派的画） | 色彩交融、朦胧流动 |
| 炼字（渗） | 颜色如可流动 |
| 意境营造 | 雨 + 丁香 = 诗意与愁韵 |

---

## 第5段｜恍然悟“结”

> 小小的花苞圆圆的，鼓鼓的，恰如衣襟上的盘花扣。我才恍然，果然是丁香结。

| 手法 | 作用 |
|------|------|
| 比喻（盘花扣） | 落实“结”的外形本义 |
| 叠词 | 形态可感 |
| 顿悟叙事 | 赏花转向悟理的枢纽 |

**本义**：花苞如盘花扣。  
**后文象征**：人生解不完的烦恼、愁怨。

---

## 第6段｜象征与主旨

### 句①
> ……真觉得它们负担着解不开的愁怨了。每个人一辈子都有许多不顺心的事……所以丁香结年年都有。

| 手法 | 作用 |
|------|------|
| 拟人（负担） | 愁怨压在花上 |
| 联想→象征 | 外形结 → 人生结 |
| 类比 | 年年有结 = 人生常态 |

### 句②（主旨）
> 结，是解不完的；人生中的问题也是解不完的，不然，岂不太平淡无味了吗？

| 手法 | 作用 |
|------|------|
| 反问 | 强化语气 |
| 翻新旧意 | 一反古人纯写愁怨 |
| 托物言志 | 豁达、从容面对人生 |

---

## 手法速查

| 手法 | 例子 | 效果 |
|------|------|------|
| 比喻 | 星星、盘花扣、印象派的画 | 形象具体 |
| 拟人 | 探、窥、潇洒、负担 | 情态生动 |
| 借代/借喻 | 积雪、莹白 | 突出特征 |
| 引用 | 芭蕉不展……雨中愁 | 文化厚度 |
| 象征 | 丁香结 | 人生难题 |
| 反问 | 岂不太平淡无味了吗 | 点明态度 |

---

## 读写迁移（三招）

1. **多角度写物**：形、色、味、姿  
2. **一个意象两层意思**：外形 + 象征  
3. **翻新旧意**：古人如何看 → 我如何看
