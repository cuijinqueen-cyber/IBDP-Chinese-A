评分可使用校内量规，或映射 IB Paper 2 / IO / HL Essay 标准语言。

## A. 形成性评估

### A1 批注日志（每精读篇目）

| 项目 | 说明 |
|------|------|
| **类型** | Formative / Homework + Class |
| **描述** | 双栏批注：左栏情节人物；右栏手法→效果→与概念/GI 的联系。每篇至少 6 处有效批注。 |
| **成功标准** | 批注指向语言选择；有效果说明；至少 2 处连到 Culture / Identity / Perspective / Representation |
| **反馈** | 抽样详批；同伴用「星—星—愿望」互评 |
| **档案** | 必收 |

### A2 概念迁移卡（Week 1–2）

| 项目 | 说明 |
|------|------|
| **描述** | 正面：概念定义（课初）。背面：用《永远的尹雪艳》一例修订定义。 |
| **目的** | 显化概念学习，避免标签化 |

### A3 短写（300–500 字）

**题干示例（选一）：**
1. 分析《永远的尹雪艳》中**一处重复或对照**如何呈现「时间」与文化心态。  
2. 分析《一把青》中**结构安排**如何塑造创伤的显现或压抑。  
3. 分析《花桥荣记》中**叙述声音**如何影响读者对人物的判断。

**评分重心**：Analysis & Evaluation；Language（次要）。

### A4 迷你 Individual Oral（Week 7）

| 项目 | 说明 |
|------|------|
| **时长** | 论述 6–8 分钟 + 问答 2–3 分钟（课堂简化版） |
| **材料** | 《台北人》摘录 1 + 非文学文本 1 |
| **要求** | 明确 GI；两文本均衡；手法与意义并重 |
| **反馈** | 录音自评清单 + 教师 3 点建议 |

## B. 总结性评估选项

### B1 比较论文（对接 Paper 2）

**任务名称（ManageBac）**：Summative — 《台北人》比较分析论文

**说明（可贴进任务描述）：**  
从本单元精读篇目中选择两篇，回应下列题目之一（或经教师批准的自拟比较题）：

1. 比较两篇作品如何呈现「过去」对人物当下生存的塑形。  
2. 比较两篇作品中**空间（城市/室内/舞台）**如何成为文化身份的象征。  
3. 比较两位女性人物的「自我呈现」策略及其代价。  
4. 比较不同叙事视角如何引导读者对「失落」的理解。

**要求：**
- SL：800–1000 字｜HL：1000–1200 字（可按校本调整）  
- 必须有清晰论点；文本证据充分；比较贯穿而非两段拼贴  
- 恰当引用并注明篇名

**标准语言（校内可用）：**
- A 理解与洞察  
- B 分析与评价（手法—效果—意义）  
- C 焦点与组织（比较结构）  
- D 语言

**提交**：ManageBac Dropbox；建议开启原创性检测（若学校启用）。

---

### B2 个人口头论述（对接 IO）

**任务名称**：Summative — Individual Oral 演练（《台北人》+ 非文学）

**全球性问题**：学生自拟，须课前经教师确认（具体、可辩论、可双文本证明）。

**结构建议（给学生）：**
1. 开场：GI + 两文本如何相关（1′）  
2. 文学摘录：内容与形式如何呈现 GI（4′）  
3. 非文学文本：内容与形式如何呈现 GI（3′）  
4. 综合：比较/对照深化对 GI 的理解（1–2′）  
5. 问答（5′）

**教师观察点：**
- GI 是否空泛  
- 是否只讲情节不谈形式  
- 两文本是否失衡  
- 时间管理  

**记录**：录音存档（学习者档案）；分数可作校内总结性成绩。

---

### B3 HL Essay 方法草稿（仅 HL，可选）

**任务名称**：HL Essay Groundwork — 《台北人》探究线与分析草稿

**交付：**
1. 探究线（Line of Inquiry）1–2 句 + 为何值得探究  
2. 1200–1500 字分析草稿（可聚焦单篇或跨篇，但须足够窄）  
3. 自我评估：对照 HL Essay 标准的优势/缺口  

**说明**：此为方法训练，不替代正式 HL Essay 最终提交。

## D. 成功标准（学生可见版）

### 论文
- 我有一个贯穿全文的比较论点。  
- 我分析的是作者选择，而不只是人物命运。  
- 每段都有「证据 → 阐释 → 回扣论点」。  
- 我的结论回答了题目中的概念问题。

### IO
- 我的全球性问题具体且可辩论。  
- 我均衡讨论文学与非文学。  
- 我谈到形式（镜头/布局/修辞/结构等）如何制造意义。  
- 我能回答追问并回到文本。
