# 《台北人》ManageBac 单元计划

本文件夹为 **IBDP 中文 A：文学 / 语言与文学** 课程设计的 ManageBac 单元计划，围绕白先勇短篇小说集《台北人》编写。

## 文件说明

| 文件 | 用途 |
|------|------|
| `managebac-unit-plan.md` | 按 ManageBac DP Unit Planner 字段填写的完整单元计划（可直接复制粘贴） |
| `weekly-sequence.md` | 6–8 周教学序列与课时建议 |
| `assessment-tasks.md` | 形成性 / 总结性评估任务说明（对接 Paper 2、IO、HL Essay） |
| `index.html` | 网页版预览，便于浏览与打印 |

## 如何录入 ManageBac

1. 打开班级 → **Tasks & Units** → **Add Unit**
2. 填写标题、起止日期与周数（建议 6–8 周 / 约 30–40 学时）
3. 在 **Planner** 中按下列分区粘贴对应内容：
   - **Summary** ← 单元概要
   - **Inquiry & Purpose** ← 迁移目标、本质理解、探究问题、易误解概念
   - **Curriculum** ← 学科宗旨、探索领域、概念、大纲内容
   - **Connections** ← TOK / CAS
   - **Approaches to Learning** ← ATL 技能与学习者培养目标
   - **Design & Implement** ← 教学内容、学习体验、差异化、评估
   - **Reflect** ← 教学前/中/后反思提示（实施后填写）
4. 在 **Assessments** 中新建任务，并勾选对应评估目标 / 标准
5. 在 **Stream & Resources** 中上传文本、讲义与学习体验

## 课程定位建议

- **探索领域**：以「时间与空间」为主；辅以「读者、作者与文本」「互文性」
- **核心概念**：文化、身份认同、视角、呈现
- **全球性问题**：文化身份、归属与流散、记忆与社群
- **评估对接**：学习者档案、Paper 2 比较写作、个人口头论述（IO）、HL Essay 选题铺垫
