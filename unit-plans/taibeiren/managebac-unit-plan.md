| 字段 | 内容 |

| **Unit Title / 单元标题** | 台北人：流散记忆中的文化身份与时代空间 |
| **Subject / 学科** | Language A: Literature（中文 A：文学） |
| **Level / 级别** | SL / HL（混合班可共用框架，HL 加深度比较与 HL Essay 铺垫） |

| **At-a-Glance 简介（给学生/家长）** | 本单元研读白先勇《台北人》，探究迁徙、记忆与文化身份如何在台北的时空中被书写，并训练文本细读、比较写作与全球性问题论述能力。 |

### 建议精读篇目（可按班情调整）

1. 《永远的尹雪艳》——传奇形象与时间凝固  
2. 《一把青》——战争创伤与情感结构  
3. 《花桥荣记》——乡愁、失落与叙事声音  
4. 《金大班的最后一夜》——身体、欲望与社会阶层  
5. 《游园惊梦》——互文、戏曲与记忆崩解  
6. 《国葬》／《梁父吟》（二选一或拓展）——历史、权力与世代落差  

### 可选比较文本（Intertextuality / Paper 2 / IO）

- 张爱玲《金锁记》或《倾城之恋》（都市、女性、时代）  
- 老舍《茶馆》（时代空间与人物群像）  
- 聂华苓《桑青与桃红》选章（流散身份）  
- 非文学文本：老照片、纪录片片段、移民口述史、台北城市空间影像（服务 IO）

## 二、INQUIRY & PURPOSE｜探究与目的

### 2.1 Transfer Goals｜迁移目标

学完本单元后，学生能够：

1. **迁移细读方法**：在未见过的文学文本中，识别作者如何通过叙事视角、意象、结构与互文创造意义。  
2. **迁移概念框架**：用「文化 / 身份认同 / 视角 / 呈现」解释其他文本或现实情境中的归属、流散与记忆议题。  
3. **迁移评估技能**：将本单元分析迁移到 Paper 1（手法意识）、Paper 2（比较论证）、Individual Oral（全球性问题 + 文学/非文学联结）及 HL Essay（探究线）。  
4. **迁移批判立场**：区分「主题概括」与「有证据的文学阐释」，避免把人物简化为历史说明书。

### 2.2 Essential Understandings｜本质理解

1. 文学作品通过**特定时空与叙事选择**，呈现文化身份如何在迁徙、断裂与记忆中被建构与改写。  
2. 《台北人》中的「台北」不仅是地理背景，更是**权力、阶级、性别与乡愁交汇的象征空间**。  
3. 白先勇以传奇化人物、戏曲互文与细腻感官书写，使个人命运成为**集体流散经验的呈现**。  
4. 读者对文本意义的理解，受自身文化位置与时代语境影响；阐释需同时回应**文本证据与接受语境**。

### 2.3 Inquiry Questions｜探究问题

| 类型 | 探究问题 |
|------|----------|
| **Factual 事实性** | 《台北人》写于何时？主要人物来自怎样的历史迁徙背景？各篇主要场景与叙事人称是什么？ |
| **Conceptual 概念性** | 「文化」如何通过人物的语言、仪式、服饰与空间被呈现？「身份认同」在流散经验中如何被巩固或瓦解？叙事视角如何塑造我们对「台北人」的理解？ |
| **Debatable 辩论性** | 《台北人》是在追悼一个失落的世界，还是在批判那个世界？文学对历史创伤的美化是否伦理上正当？「乡愁」是抵抗遗忘，还是阻碍新生？ |

### 2.4 Missed Concepts / Misconceptions｜易误解概念

| 易误解 | 澄清与教学对策 |
|--------|----------------|
| 把《台北人》读成「历史课本」或单纯怀旧 | 强调作者选择、虚构策略与反讽；追问「如何写」而非仅「写什么」 |
| 把所有人物等同于「外省人」刻板印象 | 细读阶层、性别、职业差异；比较尹雪艳、朱青、金大班等 |
| 把「悲剧」当作唯一结论 | 讨论传奇美学、荒诞、黑色幽默与同情的复杂并存 |
| 全球性问题写成空泛口号（如「身份很重要」） | 要求：具体场域 + 文本证据 + 可辩论立场 |
| 互文只列出处不谈效果 | 以《游园惊梦》示范：互文如何组织记忆与崩解 |

## 三、CURRICULUM｜课程内容

### 3.1 Aims｜学科宗旨（勾选相关）

- 欣赏语言的美学与力量，并欣赏文学文本的细微差别  
- 在对文学文本的回应中发展批判性、创造性思考  
- 加深对文本与读者、作者及多元语境之间关系的理解  
- 培养对语言如何创造意义的认识  
- 培养对文学传统与文学形式的欣赏  
- 发展对文本所呈现的人类经验与关切的理解  
- 培养国际情怀，理解文化身份的多元与复杂性  

### 3.2 Areas of Exploration｜探索领域

| 探索领域 | 本单元如何落实 |
|----------|----------------|
| **时间与空间 Time and space（主）** | 1949 前后迁徙、台北作为流散空间、过去/现在并置、世代差异 |
| **读者、作者与文本 Readers, writers and texts（辅）** | 白先勇的创作语境与读者接受；叙事声音、人称、细节如何引导阐释 |
| **互文性：连接文本 Intertextuality（辅）** | 《游园惊梦》与昆曲《牡丹亭》；可与张爱玲、老舍等比较；文学—非文学配对（IO） |

### 3.3 Concepts｜七大概念（本单元聚焦）

| 概念 | 在本单元中的含义 |
|------|------------------|
| **Culture 文化** | 礼教、交际仪式、饮食、戏曲、上海/台北生活方式如何构成身份符号 |
| **Identity 身份认同** | 「台北人」命名的张力：地理归属 vs 精神原乡；性别、阶层、世代身份 |
| **Perspective 视角** | 第一人称不可靠/受限叙述、旁观同情、集体群像如何影响意义 |
| **Representation 呈现** | 传奇化、象征、空间隐喻、身体书写如何呈现历史与创伤 |
| （拓展）**Transformation 转化** | 人物从大陆到台北的身份转化；记忆如何改写过去 |
| （拓展）**Communication 交流** | 方言、称谓、沉默与表演如何传递权力与亲密 |
| （拓展）**Creativity 创意** | 作者如何创造性重组历史材料为文学结构 |

### 3.4 Syllabus / Learning Outcomes｜学习结果

学生将能够：

1. **Know / Understand**：说明《台北人》的历史语境、体裁特征与主要人物关系网络。  
2. **Interpret**：阐释关键意象、结构与互文如何产生多重意义。  
3. **Analyze**：分析语言选择（感官细节、反讽、对照、时间处理）如何建构文化身份与流散经验。  
4. **Compare**：在两篇（或文学+非文学）之间建立有概念支撑的比较论点。  
5. **Evaluate**：评估不同阐释的合理性，并对全球性问题提出有证据的立场。  
6. **Communicate**：以清晰结构完成书面分析与口头论述，恰当引用文本。

### 3.5 Assessment Objectives｜评估目标对应

| AO | 本单元证据 |
|----|------------|
| 理解并阐释文本意义与语境 | 语境短讲、注释日志、研讨 |
| 分析并评价语言/文学手法 | 细读作业、Paper 2 风格写作 |
| 沟通：清晰、有条理、有说服力 | 口头汇报、IO 演练、论文 |

## 四、CONNECTIONS｜联系

### 4.1 TOK Connections｜知识论联系

| TOK 问题 | 课堂切入 |
|----------|----------|
| 历史知识与文学知识有何不同？文学能否「认识」过去？ | 对比史料叙述与《国葬》《一把青》的文学叙述 |
| 记忆是可靠的知识来源吗？ | 《游园惊梦》《花桥荣记》中的回忆偏差与自我保护 |
| 文化如何塑造我们看见/看不见什么？ | 读者对「外省人」「上海小姐」等标签的先入之见 |
| 艺术作品的美化是否扭曲真相？ | 辩论：传奇美学 vs 历史创伤的伦理 |

### 4.2 CAS Connections｜CAS 联系（可选）

- **Creativity**：改编某篇为短剧独白 / 视觉叙事册 / 播客朗读评注  
- **Activity / Service**：采访社区中有迁徙或跨文化经验者（伦理规范前提下），反思「归属」  
- 将 CAS 反思写入学习者档案，但不替代文学评估

### 4.3 Language & Learning｜语言与学习

- 学术词汇库：流散、乡愁、互文、反讽、不可靠叙述、象征空间、全球性问题  
- 句架支持：比较段、论点—证据—阐释、IO 开场与过渡  
- 读写结合：批注 → 口头 → 短写 → 长写

### 5.2 IB Learner Profile｜学习者培养目标

- **Inquirers 探究者**：围绕探究问题持续追问「如何」与「为何」  
- **Thinkers 思考者**：处理矛盾阐释与伦理辩论  
- **Communicators 交流者**：书面与口头清晰呈现论证  
- **Open-minded 胸襟开阔**：理解流散经验与文化差异  
- **Reflective 反思者**：检视自身文化位置如何影响阅读

## 六、DESIGN & IMPLEMENT｜设计与实施

### 6.1 Content Outline｜内容大纲（按周）

详见同目录 `weekly-sequence.md`。概要：

| 周次 | 焦点 | 核心篇目 |
|------|------|----------|
| W1 | 单元启动：语境、概念、全球性问题 | 序言/总览 + 《永远的尹雪艳》 |
| W2 | 传奇形象与时间 | 《永远的尹雪艳》精读 |
| W3 | 创伤、情感结构与叙事 | 《一把青》 |
| W4 | 乡愁、声音与失落 | 《花桥荣记》 |
| W5 | 性别、身体与阶层 | 《金大班的最后一夜》 |
| W6 | 互文、记忆与崩解 | 《游园惊梦》 |
| W7 | 比较与全球性问题整合 | 跨篇比较 + 非文学配对 |
| W8 | 评估与反思 | 总结性评估 + 档案整理 |

（可压缩为 6 周：合并 W2–W3、W7–W8。）

### 6.2 Learning Experiences｜学习体验（可录入 Stream）

1. **概念墙启动**：学生用生活例子定义「文化 / 身份认同」，再对照文本修订定义。  
2. **双栏批注**：左栏「情节/人物」，右栏「手法→效果→概念」。  
3. **人物地图**：以「原乡—台北—失落/坚守」绘制关系与空间移动。  
4. **声音工作坊**：改写同一场景的不同人称，讨论视角如何改变同情与判断。  
5. **互文侦探**：《游园惊梦》中戏曲引文功能卡片分类（氛围 / 人物心理 / 结构反讽）。  
6. **全球性问题工作站**：把宽泛话题收窄为可辩论的 GI 陈述句。  
7. **比较矩阵**：两篇在意象、结构、视角、文化符号上的异同。  
8. **迷你 IO**：1 个文学摘录 + 1 个非文学文本，10 分钟论述。  
9. **Paper 2 限时段**：40–50 分钟比较写作。  
10. **档案策展**：学生自选 3 件作品并写「为何对评估有用」。

### 6.3 Differentiation｜差异化

| 学习者需求 | 策略 |
|------------|------|
| 需要更多支架 | 提供批注符号表、段落句架、精读摘录包 |
| 需要挑战（尤其 HL） | 增加理论透镜（心理分析/新历史主义简介）、第三文本比较、HL Essay 探究线草稿 |
| 语言支持 | 关键词表、范例段、允许先口头后书面 |
| 阅读负荷 | 核心篇全班精读；拓展篇分组专家汇报 |
| 评估选择 | 总结性任务提供题干选项（人物聚焦 / 空间聚焦 / 互文聚焦） |

### 6.4 Inclusive & Wellbeing Notes｜包容与福祉

- 战争、性交易、衰老、死亡等主题需事先说明，提供退出/替代任务通道。  
- 讨论流散与身份时，避免将学生个人背景当作「教材」。  
- 强调多元阐释，反对歧视性概括。

## 七、ASSESSMENT｜评估

详细任务见 `assessment-tasks.md`。

### 7.1 Formative｜形成性（过程）

| 任务 | 目的 | 反馈方式 |
|------|------|----------|
| 批注日志（每篇） | 细读与手法意识 | 抽样批改 + 同伴互评 |
| 概念迁移卡 | 概念理解 | 课堂即时反馈 |
| 研讨贡献 | 口头论证 | 成功标准清单 |
| 短写（300–500 字） | 论点—证据—阐释 | 标准 A/B 简评 |
| 迷你 IO 演练 | 全球性问题表达 | 录音自评 + 教师要点 |

### 7.2 Summative｜总结性（建议二选一或组合）

**选项 A（偏 Paper 2）**  
比较论文：自选两篇《台北人》短篇，回应教师提供的比较题（或自拟经批准的题目）。  
字数：SL 800–1000；HL 1000–1200（校内可调）。

**选项 B（偏 Individual Oral）**  
个人口头论述：自选《台北人》摘录 + 一个相关非文学文本，围绕一个全球性问题进行 10 分钟论述 + 5 分钟问答。

**选项 C（偏 HL Essay 铺垫，HL）**  
探究线提案 + 1200–1500 字分析草稿（非最终 HL Essay，重在方法）。
