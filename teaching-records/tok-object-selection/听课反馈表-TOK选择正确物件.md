## 教学目标达成 Achievement of teaching objectives

本节课目标清楚：让学生理解 TOK Exhibition 中「正确物件」不是好看或稀奇，而是能与指定提示语（prompt）建立具体、可论证的知识联系。学生课后应能区分「主题相关」与「知识论相关」，并用清单检验自己的候选物件。当堂多数学生能指出至少一处不合格选择（如过于宽泛的照片、纯装饰品、无法说明“我如何知道”的物件），并能改写联系句。目标基本达成；个别学生仍把物件当成专题展示道具，需下次一对一纠正。

## 课堂设计 Instructional Design

流程合理：复习 Exhibition 要求 → 展示合格/不合格物件对比 → 三问检验法（关联哪条 prompt？体现何种知识问题？为什么是这个物件而不是同类替代品？）→ 小组互评候选物件 → 个人修订一句话论证。设计紧扣「选择标准」，不是空讲理论。若补充 2 分钟「个人语境（personal context）」示例，学生更易避免选大众符号却说不出自身联系。时间分配上，互评可再压缩 3 分钟，留给修订写作。

## 学生学习参与度 Learning Engagement

参与度高。对比案例阶段笑声与质疑并存，说明判断标准被激活；小组互评时多数能使用教师提供的句架：「这个物件与 prompt 的联系是……；若不成立，是因为……」。有学生主动否定自己原先选的「地球仪」，承认太宽泛，体现真实学习。少数学生仍犹豫不发言，教师巡视时用「先说它不能证明什么」降低开口难度，效果较好。

## 课堂管理 Classroom Management

指令明确：何为合格物件、互评轮次、时间提醒均清楚。物件照片投影清晰，过渡干脆。讨论偶有跑题到「这个东西贵不贵」，教师迅速拉回「它对知识主张有何贡献」。课堂秩序良好，尊重不同选择，未出现嘲笑他人物件的情况。整体管理支持探究而非压制讨论。

## 详细反馈 Detailed Feedback

**课的优点**

1. **标准可操作。** 「正确物件」被落实为可检查的条件：具体、真实、与 prompt 有明确知识联系、能说明个人语境、可被替代品测试「为什么是它」。学生带走的是方法，不是口号。  
2. **反例教学有效。** 不合格案例（风景照、抽象海报、与 prompt 仅主题相似的网红物件）帮助学生看见常见失误，比只讲优秀范例更管用。  
3. **产出可见。** 课末要求每人交「物件名称 + prompt 编号 + 一句知识联系」，便于教师课后诊断。

**可改进之处**

1. **知识问题（KQ）显度不够。** 部分学生能说物件「和伦理有关」，但说不清背后的知识问题（如“道德判断依赖情感还是理性？”）。可再示范一次从物件倒推 KQ。  
2. **学科物件与生活物件的平衡。** 可提醒：实验仪器、作文原稿、校服等同样有效，避免全班只选手机壳、球鞋等同质化物件。  
3. **下一步衔接。** 建议预告下次课练「三物件如何形成整体论述」，防止学生三个物件各说各话。

**总体评价**

这是一节指向明确、实践性强的 TOK Exhibition 准备课。学生从「选一个有意思的东西」转向「选一个能支撑知识主张的东西」，核心转变已经发生。建议教师收集课末一句话，按「联系清晰 / 仍主题化 / 物件过宽」三类反馈，作为下节分层指导依据。
